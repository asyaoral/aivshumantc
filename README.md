# AI vs. Human — Text Classification | COE025 NLP Project 1

**Objective:** classify long-form English text as AI-generated (`0`) or human-written (`1`). Main data is the team's augmented corpus. The 200-example flipped-label diagnostic is **not** merged with the primary dataset.

This is a **VS Code / Python** refactor of our earlier machine-learning notebook, not an extra independent experiment. It provides a readable, leakage-aware pipeline with dataset cleaning, reproducible training, an internal benchmark, ablation experiments, and one held-out evaluation.

## One-time setup: VS Code on Mac

1. Open this folder in VS Code (**File → Open Folder**).
2. Open **Terminal → New Terminal** and run:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

3. Open `AI_vs_Human_Text_Classification_augmented.numbers` in Apple Numbers. Choose **File → Export To → CSV**, then save the CSV as `data/raw/ai_vs_human.csv` inside this folder. Check header `Text,Class`. If CSV has unexpected extra sheets / tables, export only the primary table.

## Run the entire benchmark

```bash
python -m src.train --data data/raw/ai_vs_human.csv
```

This command cleans the data, checks for 1,000+ usable examples, generates `data/processed/cleaned.csv`, conducts model selection using training-only five-fold CV, and scores an untouched 20% test partition once. Results appear in `outputs/latest/`.

Optional separate cleaning command:

```bash
python -m src.preprocess --input data/raw/ai_vs_human.csv
```

Optional tests and prediction:

```bash
python -m pytest -q
python -m src.predict --text "Example passage to classify."
```

### Model benchmark and metric

- **Baselines:** Multinomial Naive Bayes, Logistic Regression, Linear SVM.
- **Ablations:** SVM with / without stop words; SVM with TF-IDF alone vs. TF-IDF + six linguistic features.
- **Text features:** TF-IDF word unigrams and bigrams, up to 5,000 features. TF-IDF and scaling learn their parameters inside each training fold; no vocabulary leakage from holdout.
- **Selection:** maximum **mean five-fold macro-F1** on the 80% training partition. This treats AI and Human equally. Also report CV accuracy, F1 standard deviation, and final test accuracy, macro precision/recall/F1 and confusion matrix.
- **Critical limitation:** Scores on this corpus may exploit topic / dataset source differences. They do not prove AI authorship in general.

### Benchmark results (verified locally in VS Code)

**Reproduced and verified:** The complete training and evaluation pipeline was successfully reproduced locally in VS Code using the augmented corpus (`data/raw/ai_vs_human.csv`, SHA-256: `bd5454ec76ed9355d371da77f28fc70de6a38cad0dc1b7a0e47dec593b1b79b9`). Starting from 3,402 raw samples, preprocessing yielded exactly 3,382 clean passages (1,698 AI, 1,684 Human). Under stratified 5-fold cross-validation on the 80% training set, Linear SVM achieved the top mean Macro-F1 of **0.9896 ± 0.0022**, Logistic Regression achieved **0.9834 ± 0.0061**, and Naive Bayes reached **0.8904 ± 0.0179**. On the untouched 20% holdout (677 samples), the selected Linear SVM achieved **98.23% accuracy** and **0.9823 Macro-F1** with exactly **12 misclassifications** (6 AI→Human, 6 Human→AI). All generated metrics and figures are recorded in `outputs/latest/`.

Research context: [HC3 (Guo et al., 2023)](https://arxiv.org/abs/2301.07597), [SemEval-2024 Task 8](https://aclanthology.org/2024.semeval-1.148/), and [RAID (Dugan et al., 2024)](https://aclanthology.org/2024.acl-long.674/). Their metrics are not numerically comparable unless dataset/split/protocol are aligned. Read `docs/benchmark.md`.

## Notes on the 200 flipped-label file

`train_essays_200_flipped_labels.numbers` is not used in the main benchmark. Its name suggests intentional label changes. Do not use its apparent perfect score as evidence of trustworthy authorship detection. It has fewer than 1,000 examples and warrants separate, documented diagnostic experiments only.
