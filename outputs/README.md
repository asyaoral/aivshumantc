# Benchmark Outputs
 
This directory contains reproducible benchmark deliverables generated by `python -m src.train`.

Verified results generated in `outputs/latest/`:
- `data_quality.json`: Data cleaning summary, class counts, and input SHA-256 fingerprint.
- `cv_benchmark.csv`: Stratified 5-fold cross-validation metrics across all five model configurations.
- `holdout_metrics.csv`: Single holdout evaluation results (Accuracy: 0.9823, Macro-F1: 0.9823).
- `classification_report.json`: Detailed per-class precision, recall, and F1 scores.
- `cv_benchmark.png`: Cross-validation Macro-F1 comparison chart.
- `confusion_matrix.png`: Holdout confusion matrix plot.
- `error_summary.csv`: Distribution of misclassifications (6 AI→Human, 6 Human→AI).
- `private/misclassified_texts_private.csv`: Raw text of misclassified passages (local only, ignored by Git).
- `selected_model.joblib`: Serialized trained Linear SVM pipeline (local artifact, ignored by Git).

Only public-safe metrics and visualization artifacts are tracked in the repository.
